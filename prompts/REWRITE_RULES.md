# CV Rewrite Rules

## Core principle

The base CV is the factual source of truth.

The rewrite may change:
- wording
- ordering
- emphasis
- concision
- keyword selection
- bullet structure
- summary positioning

The rewrite may NOT change factual reality.

## Never invent

Never invent:
- employers
- job titles
- employment dates
- degrees
- certifications
- skills
- programming languages
- software
- responsibilities
- projects
- clients
- industries
- metrics
- percentages
- revenue
- budgets
- team sizes
- awards
- promotions
- locations
- security clearances
- language proficiency
- achievements

If the job description asks for something unsupported, omit it or identify it as a gap. Never silently add it.

## Evidence hierarchy

Use information in this order:

1. Explicit facts in the base CV
2. Clearly equivalent wording supported by the base CV
3. Conservative synthesis of multiple supported facts
4. Never use unsupported assumptions

Example:

Base CV: "Created automated reports using Python."

Allowed:
"Automated reporting workflows using Python."

Not allowed:
"Built production-grade Python data pipelines processing millions of records."

The second statement adds unsupported scale and technical depth.

## Quantification

Preserve source metrics exactly.

You may improve wording around a metric, but do not:
- create a metric
- round a metric
- convert a metric
- infer a metric
- turn a vague claim into a precise claim

If no number exists, use qualitative language.

## Job-description alignment

For every important job requirement, classify it as:

- MATCH — directly supported
- PARTIAL — related evidence exists
- GAP — no evidence

Only MATCH and PARTIAL items may influence the rewrite.

A GAP must never be converted into a claimed qualification.

## Truth-preserving paraphrasing

The rewrite should sound natural and professional, but every statement must remain defensible from the base CV.

When uncertain, prefer the less specific statement.

## Review requirement

Before accepting a rewrite, verify:

- Every employer exists in the base CV.
- Every role exists in the base CV.
- Dates are unchanged.
- Education is unchanged.
- Certifications are unchanged.
- Skills are supported.
- Metrics are supported.
- No new technology has been introduced.
- No unsupported achievement has been introduced.
- Job-description keywords are used only where evidence exists.

Return a FAIL result if any factual claim cannot be traced to source evidence.
